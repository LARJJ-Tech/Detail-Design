# Team File Naming Convention

## General Rules
- Use camelCase within each document section.
- Separate document sections with an underscore _.
- Folders may include spaces.
- Capital letters are allowed, but do not use all caps.
- Keep names short, clear, and consistent.
- Avoid special characters (e.g. @,#,$,&)

## Folder Naming Convention
- Folders should clearly describe their contents and follow a logical structure.
- Example:
 - Gas Turbine / Compressor Analysis

## Document Naming Convention 
Document names must use camelCase for each section, with underscores separating the sections. Author initials and version must be appended to the end of the document name.

`component_description_intialsVersion`

- Example:
 - HPC_firstStagePerformance_JB1
